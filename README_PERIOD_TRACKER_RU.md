# Luna - Telegram Бот для Отслеживания Менструального Цикла

Luna - это Telegram бот для отслеживания менструального цикла с возможностью обмена данными с партнером и AI-помощником через интеграцию с roocode.

## Возможности

### 🩸 Отслеживание Цикла
- Отслеживание начала и конца месячных
- Автоматический расчет длины цикла
- Учет продолжительности месячных
- Мониторинг интенсивности выделений (шкала 1-5)
- Запись симптомов

### 📊 Прогнозы и Аналитика
- Прогноз даты начала следующих месячных
- Расчет окна фертильности
- Определение дат овуляции
- Анализ регулярности цикла
- Историческая статистика

### 👫 Обмен Данными с Партнером
- Генерация уникальных кодов-приглашений
- Обмен информацией о цикле с партнером
- Партнер может просматривать прогнозы
- Система подключения с фокусом на приватность

### 🤖 Интеграция с AI
- Пересылка вопросов в roocode AI
- Контекстно-зависимые ответы на основе данных цикла
- Взаимодействие на естественном языке
- Персонализированные рекомендации

## Структура Базы Данных

### Таблицы

#### `periods`
- Отслеживает записи о месячных
- Поля: start_date, end_date, duration, flow_intensity, symptoms, notes

#### `partners`
- Управляет связями с партнерами
- Поля: user_id, partner_id, invitation_code, status, accepted_at

#### `telegram_users` (обновлена)
- Добавлены поля: partner_code, average_cycle_length, average_period_length, gender

## Команды Бота

### Команды для Отслеживания Цикла
- `/start_period [дата]` - Начать отслеживание месячных (дата необязательна, по умолчанию сегодня)
- `/end_period [дата]` - Завершить текущие месячные (дата необязательна, по умолчанию сегодня)
- `/status` или `/period_status` - Просмотреть текущий статус цикла и прогнозы

### Команды для Партнера
- `/invite_partner` - Сгенерировать код-приглашение и ссылку для партнера
- `/connect_partner КОД` - Подключиться к партнеру используя его код
- `/partner_status` - Просмотреть информацию о цикле партнера
- `/remove_partner` - Удалить связь с партнером

### Общие Команды
- `/start` - Приветственное сообщение и введение в бот
- `/help` - Показать все доступные команды

### AI Запросы
Просто напишите свой вопрос на естественном языке, и бот переправит его в AI:
- "Когда у меня следующие месячные?"
- "Я сейчас в периоде фертильности?"
- "Какие симптомы нормальны во время месячных?"

## Инструкции по Установке

### 1. Конфигурация Окружения

Добавьте в ваш `.env` файл:

```env
# Конфигурация Telegram Бота
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_BOT_USERNAME=имя_вашего_бота
TELEGRAM_WEBHOOK_URL=https://вашдомен.com/api/telegram/webhook

# Интеграция с Roocode AI
ROOCODE_API_URL=http://localhost:3000/api/ai
ROOCODE_API_KEY=ваш_ключ_roocode_api
```

### 2. Запустите Миграции

```bash
php artisan migrate
```

Это создаст следующие таблицы:
- `periods`
- `partners`
- Обновит таблицу `telegram_users`

### 3. Настройте Telegram Webhook

```bash
php artisan telegram:set-webhook
```

### 4. Настройте Интеграцию с Roocode

Бот отправляет запросы пользователей в API roocode с контекстом, включающим:
- Текущую информацию о цикле
- Историю отслеживания месячных
- Статус окна фертильности
- Статус связи с партнером

Расширен методами отслеживания месячных:
- `startPeriod()` - Обработка команды начала месячных

- `buildUserContext()` - Построить контекст для AI запросов

## Процесс Приглашения Партнера

1. **Пользователь A генерирует приглашение:**
   ```
   /invite_partner
   ```
   Бот отвечает:
   - Уникальный код (например, `ABC123`)
   - Прямая ссылка: `https://t.me/ваш_бот?start=partner_ABC123`

2. **Пользователь B подключается:**
   - Кликает по ссылке ИЛИ
   - Использует команду: `/connect_partner ABC123`

3. **Связь установлена:**
   - Оба пользователя получают подтверждение
   - Пользователь B теперь может просматривать информацию о цикле Пользователя A через `/partner_status`

## Процесс AI Интеграции

1. Пользователь отправляет вопрос (определяется по вопросительным словам или `?`)
2. Бот строит контекст из данных отслеживания месячных пользователя
3. Запрос отправляется в API roocode с вопросом + контекстом
4. AI ответ возвращается пользователю через Telegram

## Безопасность и Приватность

- Коды партнеров уникальны и имеют ограниченный срок действия (7 дней)
- Только принятые партнеры могут просматривать информацию о цикле
- Пользователи могут удалить связь с партнером в любое время
- Все данные хранятся безопасно в базе данных
- Код партнера должен быть явно передан
